# ExpoCannabis Brasil 2026 · Mapa interativo (DEMO)

App totem + celular para a ExpoCannabis Brasil 2026 (4ª edição, 20 a 22 de novembro, São Paulo Expo). Proposta da Kionda. Dados marcados DEMO são de exemplo.

- App: https://kionda043-alt.github.io/expo-brasil-26/
- Admin: https://kionda043-alt.github.io/expo-brasil-26/admin.html

Arquivos:
- `index.html`: a app (vertical 9:16, celular e horizontal).
- `admin.html`: abre o painel de administração (`index.html#admin`). Nesta versão estática, as mudanças ficam salvas só no aparelho onde foram feitas.
- `assets/plan`: elementos da planta oficial (mapa de reservas 2026), redesenhada em vetor.
- `assets/img`, `assets/art`, `assets/video`: imagens e vídeos.
- `assets/fonts`, `assets/js`: fontes e gerador de QR.
- `manifest.webmanifest`, `icons/`, `sw.js`: instalação no celular e funcionamento offline.
